# 🏠 StayNest

**StayNest** is a full-stack accommodation and property listing web application inspired by Airbnb. It is built using **Node.js, Express.js, MongoDB, and EJS**, with a focus on dynamic property listings and a clean, responsive user experience.

## 🚀 Technologies Used

* **Node.js** – Backend runtime
* **Express.js** – Web application framework
* **MongoDB** – Database
* **Mongoose** – MongoDB object modeling
* **EJS** – Server-side templating
* **HTML5 & CSS3** – Frontend structure and styling
* **JavaScript** – Client-side functionality

## ✨ Features

* 🏠 Browse property listings
* 🔍 View detailed property information
* ➕ Create new property listings
* ✏️ Edit existing listings
* 💾 MongoDB database integration
* 🌐 Dynamic pages using EJS
* 📱 Responsive design
* 🔗 Express.js routing
* ⚡ Server-side rendering

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project

```bash
cd StayNest
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure MongoDB

Create a `.env` file in the root directory:

```env
ATLASDB_URL=your_mongodb_connection_string
```

### 5. Start the Application

```bash
npm start
```

Or, if using nodemon:

```bash
npm run dev
```

The application will run locally at:

```text
http://localhost:8080
```

## 🎯 Project Purpose

StayNest was developed as a full-stack web development project to practice building a real-world property listing platform using **Node.js, Express.js, MongoDB, and EJS**.
